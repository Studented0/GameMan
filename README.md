# GameMan
A custom handheld Game Boy emulator built around the ESP32-S3. 	USB-C for both charging and game loading.

### Specs
 
| Component | Part |
|---|---|
| MCU | ESP32-S3-DevKitC-1 N8R8 |
| Display | 3.5" IPS ST7796U, 480×320, capacitive touch |
| Touch controller | FT6336U (I2C) |
| Storage | Micro SD (built into display module) |
| Battery | 3.7V LiPo |
| Charging | TP4056 with software-controlled enable |
| Regulation | AMS1117-3.3 LDO |
| USB | USB-C (charging + USB OTG game loading) |
